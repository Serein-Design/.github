## Carousel

A walnut and aluminium desk object with an LED pixel panel. It shows the data you choose,
including what your coding agent is doing right now. One encoder, no menus, no cloud account,
and you can repair it by hand.

Learn more at [serein-design.fr](https://serein-design.fr).
